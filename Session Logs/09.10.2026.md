**Failed attempts and gotchas from this session**

- The osdk generate step rewrote `package.json` (carets on the pinned versions, a peerDependencies block). Fixed with `--skipPackageJsonUpdate` and the file restored.
- faux looks up actions camelized (`createObjectPerson`) while maker names them kebab (`create-object-person`). The engine registers under the camelized name, which is also the generated SDK's name.
- In maker's `defineLink`, each side's metadata names the link that lives ON that object (`one.metadata` is `Person.digitalAccounts`, `toMany.metadata` is `DigitalAccount.owner`). The first build had every link reversed.
- The IR converter leaves `pluralDisplayName` empty; `build.mjs` copies it from the IR.
- The generated `sdk/` fails the app's `noUnusedLocals`; it has its own `tsconfig.sdk.json`, referenced from `tsconfig.json`.
- The OSDK client refuses two operators under one property (`$gte` and `$lte` together); range filters use `$and`.
- Comparing JSON by stringify failed on key order in proofs; a canonical sort helper fixed it. faux sorts by code point, not `localeCompare`.
- pdfjs legacy build: `doc.destroy` is not a function in Node; use `cleanup`.
- A stale P0 stub engine (started with `&` in a subshell; `kill %1` did not reach it) held 8787 and answered the lift-out check with the old shape. `lsof -t -i :8787` found it.
- The police hook refuses any Bash command whose text names `pnpm-lock.yaml`, even a read. The lift-out rehearsal moved into a script file.
- A rehearsal script with `set -e` died on the first failed curl; `set +e` before polling.
- Pairs: an initial matching a word both names already share ("D." against "Dela") scored Rowena against Joaquin at 0.8. Initials now only count for a word the other name has and this one lacks.
- `pickTitle` chose "DELA PENA, JOAQUIN" as the canonical title; it now prefers mixed case and "First Last" order.
- The shortest path from P-001 to I-001 runs through the school, not the firearm. `what-connects` now returns up to five shortest paths so the firearm chain comes back too.
- Node warns "localStorage is not available" on every run. Harmless, from a dependency.
